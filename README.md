# My Weekly Planner

A personal weekly planner with task scheduling, fixed commitments, work hours, and a smart auto-planner.

---

## How to put this on the internet (free, ~10 minutes)

### Step 1 — Create a GitHub account
Go to https://github.com and sign up for a free account if you don't have one.

### Step 2 — Create a new repository
1. Once logged in, click the **+** button (top right) → **New repository**
2. Name it: `weekly-planner`
3. Leave everything else as default
4. Click **Create repository**

### Step 3 — Upload these files
On the new repository page:
1. Click **uploading an existing file** (shown on the empty repo page)
2. Drag and drop ALL the files and folders from this zip into the upload area:
   - `package.json`
   - `vite.config.js`
   - `index.html`
   - `.gitignore`
   - `src/` folder (containing `main.jsx` and `App.jsx`)
3. Scroll down and click **Commit changes**

### Step 4 — Deploy on Vercel
1. Go to https://vercel.com and click **Sign Up**
2. Choose **Continue with GitHub** — this links your accounts
3. Click **Add New Project**
4. Find and select your `weekly-planner` repository
5. Vercel will auto-detect it's a Vite/React project
6. Click **Deploy** — no other settings needed

### Step 5 — You're live!
Vercel gives you a free URL like `weekly-planner-abc123.vercel.app`

You can:
- Bookmark it on your phone/computer
- On iPhone: open in Safari → Share → Add to Home Screen
- On Android: open in Chrome → menu → Add to Home Screen

It will behave like an app icon on your home screen.

---

## Your data
Everything is saved in your browser's local storage — no account or server needed.
This means your data stays on whichever device/browser you use the app on.
